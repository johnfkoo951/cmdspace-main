## AI가 실제로 일하도록 설계합니다

**기업의 AI가 실제 업무에서 일하도록 지식·업무 흐름·사람을 함께 설계합니다.**

## 실행 방식

| 단계 | 역할 | 핵심 결과 |
|------|------|-----------|
| Discover | 임원 교육·코칭으로 문제와 스폰서 발견 | 우선 질문·과제 후보 |
| Diagnose | 지식·업무·AI 준비도와 기준선 진단 | 파일럿 범위·성공 기준 |
| Pilot | 한 부서·한 업무에 지식 구조와 AI 흐름 구축 | 작동하는 파일럿·전후 결과 |
| Scale | 수준별 교육·관리자 양성·전달체계 운영 | 조직 확산·운영 매뉴얼 |
| Operate | 지식 갱신·품질·접근 권한·경영진 코칭 설계 | 반복 가능한 지식운영체계 |

교육을 버리지 않습니다. 교육은 문제 발견·신뢰 형성·현장 검증의 입구이며, 진단과 파일럿은 교육을 실제 운영으로 전환하는 다리입니다.
