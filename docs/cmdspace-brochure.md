## 커맨드스페이스란

**CMDSPACE (커맨드스페이스)** 는 맥OS 스팟라이트 단축키 `⌘ + Space` 에서 이름을 가져온 **지식관리 브랜드** 입니다. 옵시디언 · LLM · 에이전트를 결합해, **외부에 구축한 지식 공간이 사용자의 일을 지휘하게 만드는 것** 을 지향합니다.

### 이름의 두 레이어

- **⌘ + Space (Gateway)** — 맥 안의 모든 정보로 들어가는 관문. 커맨드스페이스는 지식에 접근하는 *인터페이스 자체* 가 되기를 지향합니다.
- **Commanding Space** — 문자 그대로 *명령이 일어나는 공간*. 지식은 뇌가 아니라 외부에 배열해 조회·실행하는 것입니다.

### 포지셔닝

- 10,000+ 노트 규모의 옵시디언 볼트를 **실험실이자 교재로** 운영
- 현재 네 개의 축을 동시에 연구·교육: 옵시디언 PKM · System Files 인프라 · LLM Wiki 위성 볼트 · 9Yohan 멀티 에이전트
- 오픈 리소스는 `system.cmdspace.work` 에서 공개 (5개 시스템 문서 + 7개 공용 룰)
