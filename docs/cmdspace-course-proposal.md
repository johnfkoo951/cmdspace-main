## 제안 요약

**CMDSPACE(커맨드스페이스)**는 기업의 AI가 실제 업무에 정착하도록 지식, 업무 흐름, 사람을 함께 설계합니다. 같은 기술도 누가 듣느냐에 따라 다뤄야 할 층위가 다릅니다. 경영자는 무엇을 맡기고 무엇을 직접 판단할지를, 임원은 AI 과제를 지시하고 결재하는 기준을, 실무자는 자기 업무 한 건을 바꾸는 방법을, AX 전담 조직은 에이전트와 지식 베이스를 만들고 운영하는 방법을 묻습니다.

이 제안서는 교육을 받는 주체별로 들을 수 있는 과정을 정리한 **표준안**입니다. 사내 에이전트 교육, 하네스 구축, 팀 단위 LLM Wiki 구축 같은 특화 주제부터 전 직원 대상 범용 주제까지 한 표에 담았습니다. 실제 제안은 대상과 인원, 보안 조건, 사내에서 쓰는 도구에 맞춰 다시 짭니다.

| 형식 | 시간 | 맞는 상황 |
|------|------|-----------|
| 특강 | 60~120분 | 방향을 맞추고 공통 언어를 만들 때 |
| 실습 워크숍 | 3~8시간 | 자기 업무로 직접 해 보고 산출물을 남길 때 |
| 다차수 과정 | 2~6회 또는 수개월 | 수준별 분반, 전담자 양성, 전사 확산 |
| 1on1 코칭 | 회당 1~3시간 | 경영자 본인의 업무와 의사결정에서 시작할 때 |
| 진단과 구축 | 2~8주, 길게는 6개월 | 한 부서에서 실제로 작동하는 구조를 만들 때 |
| 자문 | 서면 또는 위원회 | 연구 설계, 도구 검토, 구축 절차에 의견이 필요할 때 |

## 과정을 설계하는 원칙

1. **본인 업무에서 시작합니다.** 청중이 실제로 하는 작업을 실습 소재로 삼습니다. 도구 목록을 나열하지 않습니다.
2. **실물로 시연합니다.** 매일 직접 운영하는 지식 시스템과 에이전트 작업 환경을 그대로 보여 드립니다.
3. **사내 도구와 보안 기준에 맞춥니다.** 조직이 쓰는 도구(ChatGPT, Claude, Gemini, Microsoft 365 Copilot, 사내 에이전트 플랫폼)를 기준으로 실습을 짭니다.
4. **산출물을 남깁니다.** 과정이 끝나면 다음 날 바로 쓸 수 있는 지시문, 문서 기준, 작업 파일이 남습니다.
5. **근거의 경계를 지킵니다.** 직접 수행한 실적, 고객이 보고한 성과, 외부 벤치마크를 구분해서 말합니다.

## 진행 방식과 보안

1. 사전 설문으로 직무와 AI 사용 수준, 반복 업무 예시를 받아 실습 주제와 난이도를 맞춥니다. 인원이 많은 과정은 설문 결과로 수준별 분반을 합니다.
2. 회사 내부 자료는 교육에 쓰지 않습니다. 실습은 업무를 본뜬 가상 문서와 공개 자료로 진행합니다.
3. 사내망에서 외부 AI 서비스 접속이 제한되면 개인 기기나 테더링 환경으로 대체합니다. 사내 플랫폼을 쓰는 과정은 접속과 권한을 사전에 함께 점검합니다.
4. 실습은 수강생 본인 계정으로 합니다. 교육 뒤에도 만든 결과물을 이어 쓰기 위해서입니다.
5. 노트북 실습이 있는 과정은 인원에 따라 보조강사가 동행합니다.
6. 1on1 코칭과 경영진 과정의 내용은 공개하지 않습니다.
