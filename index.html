CMDSPACE.
AI가 일하게 만드는 지식 구조.

CMDSPACE는 기업의 AI가 실제 업무에 정착하도록 지식·업무 흐름·사람을 함께 설계하는 기업 AX·컨텍스트 아키텍처 전문 서비스 회사입니다. 임원 교육과 코칭으로 문제를 발견하고, 진단·파일럿·조직 확산·운영체계로 연결합니다.

Positioning

도구와 교육을 실제 운영으로 연결합니다

AI 도입의 병목은 기능 부족보다 조직의 맥락·지식·책임이 흐려지는 데서 생깁니다. CMDSPACE는 세 영역을 하나의 설계로 묶습니다.

01 / Alignment

경영진과 현장을 정렬

임원 교육·코칭으로 조직의 실제 문제와 스폰서, 성공 기준을 먼저 확인합니다.

02 / Context

지식과 업무 흐름을 구조화

문서·회의·경험을 Context Pack과 검색 가능한 지식 구조로 전환해 AI가 일할 맥락을 만듭니다.

03 / Operations

책임과 품질을 운영 리듬으로

접근 권한·갱신 주기·관리자 역할·품질 기준을 문서화해 교육 뒤에도 계속 작동하게 합니다.

Engagement model

발견에서 운영까지, 다섯 단계로 연결합니다

고객의 문제·보안·데이터 성숙도에 따라 단계를 조정하며, 파일럿의 사용과 지표가 확인될 때만 확산을 권합니다.

01 Discover

문제 발견

임원 교육·코칭으로 우선 질문과 내부 스폰서를 확인합니다.

02 Diagnose

기준선 진단

AKM 루브릭으로 지식·업무·AI 준비도의 기준선을 잡고, 보안 조건과 성공 기준을 정의합니다.

03 Pilot

부서 파일럿

한 부서·한 업무에 Context Pack·LLM Wiki·AI 흐름을 구축합니다.

04 Scale

조직 확산

수준별 핸즈온·관리자 양성·전달체계로 반복 가능성을 만듭니다.

05 Operate

운영 정착

책임·갱신·품질·보안·분기 감사를 운영 리듬으로 만듭니다.

01

AI 업무 활용 · 프롬프트에서 하네스까지

AI를 잘 쓰는 사람은 묻지 않고 맡기고, 매번 설명하지 않고, 기준을 줍니다. 프롬프트 → 컨텍스트 → 하네스 → 루프 네 층으로 ChatGPT · Claude · Gemini를 실제 업무에 붙이고, 클라우드와 로컬 중 어디에 맡길지 보안 기준까지 함께 정합니다.

→ 기업·공공기관 실무자 · 전 직원 교육 · 일반 수강생
02

임원 AX · AI를 지휘하는 리더의 언어

AX는 도구 도입이 아니라 업무 재설계입니다. 에이전트의 다섯 요소(모델·도구·지식·룰·루프), AI 과제를 결재하는 여섯 질문, 위임과 판단 포기의 경계, 거버넌스와 데이터 주권을 임원의 언어로 다루고 1:1 코칭으로 잇습니다.

→ CEO · 임원 · 부문장 · 대기업·금융·공공기관 리더
03

AI가 읽는 조직 · AI-ready 데이터

데이터가 없는 게 아니라 AI가 읽지 못하는 형태로 쌓여 있을 뿐입니다. 보고용(PPT·PDF)·교환용(마크다운·JSON)·원문 세 층과 메타데이터 일곱 칸으로 부서 지식을 정본으로 만들고, NotebookLM 같은 근거형 AI를 기관 문서에 들이는 기준을 세웁니다.

→ DX·AI 조직 · 지식·데이터 담당 · 공공기관 · 임원
04

사내 에이전트 · 일을 맡기는 워크플로 설계

에이전트 교육은 도구 사용법이 아니라 일을 맡기는 설계입니다. 작업 계약, 컨텍스트 팩, 스킬, 단계와 상태, 검증과 복구를 차례로 세워 업무 한 건을 끝까지 맡기고, 작성자와 검증자, 사람 결재를 나눈 멀티 에이전트 흐름까지 다룹니다.

→ AX 전담 조직 · 개발·DX 팀 · 에이전트를 업무에 붙이려는 실무자
05

하네스 구축 · 조직의 AI 작업 환경

프롬프트 다음은 컨텍스트, 그다음은 하네스입니다. 시스템 파일과 공용 규칙, 스킬, 훅, 권한으로 AI가 회사의 규칙과 문체, 금기를 스스로 따르게 하고, 검증 루프와 성숙도 진단으로 운영 수준을 올립니다.

→ AX 전담 조직 · 팀 리더 · 사내 AI 운영 담당
06

팀 LLM Wiki · 쌓일수록 쓸모 있는 지식 베이스

Karpathy의 LLM Wiki 패턴을 팀 단위로 옮깁니다. 원천 자료를 AI가 위키 카드로 소화하고(Ingest), 묻고(Query), 점검하며(Lint), 스키마와 갱신 책임을 먼저 정하고 qmd 인덱스로 수천 개 노트를 찾게 합니다. 모은 수가 아니라 소화한 수로 세는 개인·팀 지식 베이스.

→ 연구팀 · 부서 지식관리 담당 · 팀 리더 · 지식노동자
07

옵시디언 PKM · 에이전트를 위한 볼트 설계

BASB·제텔카스텐·LYT를 한국 실무에 맞게 재구성한 CMDS 프로세스. 분류 체계, 프로퍼티 스키마, Bases, 위키링크로 개인 지식을 사람과 AI 에이전트가 함께 읽고 쓰는 구조로 만듭니다. Obsidian 101 기초부터 월간 옵시디언 심화까지.

→ 지식노동자 · 연구자 · 학생 · 콘텐츠 크리에이터
08

연구자의 세컨드 브레인

문헌 수집부터 읽기·인용·집필까지 연구 과정을 AI와 다시 짭니다. Zotero 서재를 에이전트가 함께 읽게 하고, pandoc 인용으로 Word 원고까지 잇고, 연구 데이터 분석과 보고서 작성은 근거를 남겨 검증합니다.

→ 대학원생 · 교수 · 정부출연연구기관 · 병원 연구팀
09

내 도구 직접 만들기 · 바이브코딩에서 배포까지

Claude Code · Codex에 일을 맡기고 MCP와 스킬로 도구를 연결합니다. 견적 계산기·업무 앱·웹페이지를 사서 쓰지 않고 직접 만들어 배포하며, 9Yohan 멀티에이전트 운영 사례와 AKM Index로 지식·에이전트 운영 수준을 점검합니다.

→ 개발자 · Power User · 반복 업무를 덜어 내려는 실무자
10

교육자를 위한 AI · 수업과 과정 설계

AI를 쓴 과제를 결과물보다 대화 기록과 구술로 평가하는 법, 기출문제와 교육과정으로 수업을 역설계하는 법까지. 중고등·대학·기업·공공기관 맞춤 실습 워크숍과 코호트 과정을 설계합니다.

→ 교사 · 교수 · 교육 담당자 · L&D 팀
